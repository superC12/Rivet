# Support

Use GitHub Issues for reproducible bugs and focused feature requests. Before
opening an issue:

1. Upgrade to the latest Rivet release.
2. Run `rivet doctor` and review the existing issues.
3. Remove API keys, prompts, conversation content, private hostnames, network
   addresses, and other personal information from logs.
4. Include the Rivet version, installation method, expected behavior, and
   minimal reproduction steps.

Rivet is maintained by volunteers. Support is best-effort and does not include
administration of individual home labs or third-party providers.

Report suspected vulnerabilities privately using the process in
[SECURITY.md](SECURITY.md), never through a public issue.
